# 格式转换工具 (Format Converter Pro)

一款功能全面的在线格式转换工具，支持文档、图片、视频等多种格式转换。

## 功能特性

- 📄 **标准文档转换** - Word/PDF 互转
- 🖼️ **图片格式识别** - 智能识别图片内容
- ⚙️ **参数格式转换** - 批量参数格式调整
- 📝 **Word ↔ PDF** - 文档格式互转
- 🖼️ **图片 → PDF** - 图片批量转 PDF
- 🎬 **MP4 → MP3** - 视频音频提取
- 🗂️ **PDF 合并** - 多文档合并
- 📁 **格式模板库** - 丰富的文档模板
- 🎞️ **视频压缩** - 高效视频压缩
- 💧 **添加水印** - 图片/文档批量水印

## 技术栈

- 前端: HTML5 + CSS3 + JavaScript
- 后端: Python (开发中)
- 部署: 腾讯云

## 快速开始

```bash
# 安装依赖
npm install

# 开发模式
npm run dev

# 构建
npm run build
```
